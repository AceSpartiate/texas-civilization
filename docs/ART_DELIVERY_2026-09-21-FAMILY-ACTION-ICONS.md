# Family-panel action icons — 21 September 2026

Four transparent 4-by-4 atlases deliver **53 named action icons**, covering every key currently exposed by `PANEL_ICONS`: household construction and work, shopping and travel, winter service choices, Houston's camp duties, road duties, log fetching, gathering and stock work.

Each icon uses a strong isolated silhouette, restrained frontier palette and thin dark outline so it remains readable in the panel at 34–38 CSS pixels and when a refused action is dimmed. Tools, clothing, transport and buildings are period-plausible. The hunting and butchering marks are neutral and non-graphic; no weapon points at a person.

The source PNGs were copied unchanged from built-in ImageGen. Read-only inspection confirmed genuine RGBA transparency, transparent corners and substantial clear alpha. Every mapped cell contains a distinct object. The first three atlases use 4-by-4 layouts; the eight subsistence icons use a fully occupied 4-by-2 layout, avoiding unused generated cells entirely.

These frames only present choices already sent by the server. They do not decide availability, costs, travel, service, resource changes or chore progress.
